## छापने के लिए यहाँ जाएँ · To download and print

**[`print/`](print/)** — letterhead, दान-रसीद books, the मुहर artwork for the
stamp shop, address labels, and the murti dimension plates. Every file is
print-ready; the folder's README says what paper and which shop.

## The repository

| Folder | What lives there |
|---|---|
| [`print/`](print/) | **Download-and-print masters** — the public face |
| [`brand/`](brand/) | The identity system: spec-generated marks, guidelines, fonts, stationery sources (`brand/stationery/`) |
| [`murti-3d/`](murti-3d/) | The murti measured: the parametric 3D instrument, the 7·1·4·2 grammar audit (`GRAMMAR.md`), and the dimension-plate pipeline (`plates/`) |
| [`temple-3d/`](temple-3d/) | The temple model viewer (darshan) |
| [`mandir-3d/`](mandir-3d/) | The parametric temple engine and render scripts |
| [`website/`](website/) | rtamfoundation.org |
| [`reference/`](reference/) | Design references — the final temple render (`temple_v3.jpeg`) and its lineage |

Identity, documents, and artwork are generated from
[`brand/spec/brand.json`](brand/spec/brand.json) through gated tooling
(`brand/tools/build.sh`) — nothing is hand-drawn twice. Documents speak both
scripts by rule: Devanagari leads, English echoes.

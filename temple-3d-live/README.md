# Live tour — rebuilt Ṛtambhareśvara model

Walkable three.js tour of the Blender master built from `temple-scene/scene-spec.json` (founder's shrine inches, the
reference grammar measured from the Tripo model, Scheme A interior). Exported with `temple-scene/scripts/export_web.py`;
GLBs carry flat colours plus vertex irradiance (the procedural stone and the Cycles light live in the Blender master).
The original Tripo model stays at `../temple-3d/`.

## How to view

- **Best:** open the `.html` in a browser — scroll, hover, click. That is the real experience.
- **Quick:** each folder carries rendered `.png` / `.gif` previews. GIFs are low-fps
  captures; smoothness is not representative, choreography is.
- Pages reference `../../../brand/dist/` assets and `colors.css` relatively —
  view them from inside the repo, don't copy the HTML out alone.

`index.html` in this folder is the atlas: one page linking every sample with
its status.

## Rules of the record

1. Candidates stay pure — no mixing components between them.
2. Retired/rejected work is kept, labeled, and never silently edited.
3. Every page must hold up in both registers it claims, at phone width,
   and under `prefers-reduced-motion`.

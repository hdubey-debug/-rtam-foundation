# Lit Stone

*The visual philosophy behind the Ṛtambhareśvara Mandir poster system.*

**One light in a dark field.** Everything begins with a ground that is almost black, the dark of an inner chamber, and a single object that carries all the light. The object is never framed, boxed or captioned into place. It is set down in the dark the way a lamp is set down in a room, and the dark is allowed to stay empty around it. Emptiness here is a material, measured as carefully as the object itself. The work should look as though someone spent days deciding how much dark belongs on each side.

**One width governs.** The widest course of the object, its plinth, becomes the measure of the page. The name beneath it is set to exactly that width, so that the letters read as a foundation course and the object stands on its own name. Nothing else on the page is allowed its own width without a reason. This single shared edge is what separates a composition from a picture with a caption, and it has to be exact: a mismatch of a few millimetres would be visible from across a street. The result must feel inevitable, the product of painstaking attention and of someone at the very top of their craft.

**One line, one gold.** Ornament is reduced to a hairline and a point. The hairline is the rule that already lives inside the name; on wide formats it is drawn out to the full width so that it becomes the ground itself, and both the name and the object stand on it. The point is a single small disc of gold, the only warm colour that does not belong to the object. Every other mark is the colour of ash. Colour is therefore not decoration but hierarchy: stone and tile in full colour, type in ash, one gold point, dark everywhere else.

**Type as architecture.** Letters are treated as built things with a headline course, a body and a base. The leading script is set large and never spaced out; the second script answers it at a third of the size, widely tracked, as a quiet echo. Supporting lines are few and small enough that they never compete, yet each is placed on the same axis or the same edge as something larger. Text is minimal by discipline. If a line does not help someone find the place or understand what is rising there, it is removed.

**Axis and order.** Where the object is symmetrical, everything shares its axis: emblem, finial, door and name fall on one vertical line, plan above elevation, as on a master builder's drawing. Where the format is wide, the order becomes a sentence read along the ground line. In both cases the eye is given one path and no detours. Each alignment should look as though it was checked a hundred times, because it was.

**Restraint as the finish.** Nothing glows, fades, bevels or casts a shadow. Edges are cut clean and left alone. The refinement is in what has been taken away and in the precision of what remains: master-level execution expressed as calm.

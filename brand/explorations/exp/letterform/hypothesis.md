# exp/letterform — hypothesis (Direction C, conservative hedge)

**Claim.** The identity stays typographic — no new symbol — but the letters
internalize the murti: the R's leg is re-cut with a below-baseline tail that
reaches toward the bindu (the R reaching for its root), the Devanagari ऋ is
rescaled to measured ink parity with the Latin R (the scripts become true
siblings), and vendored Marcellus gives the system a mixed-case whisper
(*Ṛtam*) beside Cinzel's ceremonial shout.

**What this direction bets:**

1. Brand equity lives in the existing wordmark; evolution beats revolution
   for a young institution's trust surfaces (deeds, receipts, signage).
2. The "R." punctuation misreading dies once the R *gestures* at its dot —
   the tail turns two objects into one motion.
3. Script parity is a measurement problem, not a taste problem: R ink height
   140u == ऋ ink height at fs 216 (was fs 210 visually undersized; the
   audit's 53%-of-canvas figure was bbox area, resolved by height parity +
   natural width).

**Variants shipped:** re-cut Ṛ monogram (sacred / dark / mono), mixed-case
Ṛtam wordmark (light / dark two-tone), parity pair strip + parity-scaled ऋ
icon, bindu-gap A/B/C study.

**Risks (named honestly):** the tail can read as a comma at certain sizes —
if this direction is picked, Phase 3 shortens/straightens the terminal
(current curve is deliberately expressive for the study); the typographic
favicon remains this direction's structural weakness (the R still mushes at
16 px — directions A/B solve what C cannot); the tail overlay must be
boolean-unioned with the glyph before production (raster-identical today).
